# 💼 Job Application Tracker REST API

A RESTful API built with **Python, Flask, and SQLite** for tracking job applications.

This project is part of my **100 Days of Building in Public** challenge.

The API allows users to manage job applications, update application status, search companies and positions, filter applications, and view application statistics.

---

## 🚀 Features

- ➕ Create job applications
- 📋 Get all applications
- 🔎 Get application by ID
- ✏️ Update applications
- 🗑️ Delete applications
- 🏷️ Filter by application status
- 🏢 Filter by company
- 🔍 Search applications
- 📊 Application statistics
- 💾 SQLite database
- ✅ Input validation
- ❌ Error handling
- 📦 JSON API responses
- 📅 Application date tracking
- 📝 Application notes
