# 📊 Expense Analytics REST API

A practical **Expense Analytics REST API** built using **Python, Flask, and SQLite**.

This project is part of my **100 Days of Building in Public** challenge.

The API allows users to create and manage expenses while also providing analytical insights such as total spending, category-wise spending, monthly spending, average expense, highest expense, and lowest expense.

---

## 🚀 Features

- ➕ Add expenses
- 📋 Get all expenses
- 🔎 Get expense by ID
- 🗑️ Delete expenses
- 🏷️ Filter expenses by category
- 📊 Overall expense analytics
- 📈 Category-wise analytics
- 📅 Monthly spending analytics
- 💰 Calculate total spending
- 📉 Calculate average spending
- 🔝 Find highest expense
- 🔻 Find lowest expense
- ✅ Input validation
- ❌ Error handling
- 💾 SQLite database persistence
- 📦 JSON API responses
