# 📝 Notes Management REST API

A practical **Notes Management REST API** built using **Python, Flask, and SQLite**.

This project is part of my **100 Days of Building in Public** challenge.

The API allows users to create, manage, search, categorize, update, delete, and pin notes.

---

## 🚀 Features

- ➕ Create notes
- 📋 Get all notes
- 🔎 Get note by ID
- ✏️ Update notes
- 🗑️ Delete notes
- 🔍 Search notes
- 🏷️ Filter notes by category
- 📌 Pin and unpin notes
- 💾 SQLite database
- 🕐 Creation and update timestamps
- ✅ Input validation
- ❌ Error handling
- 📦 JSON responses
