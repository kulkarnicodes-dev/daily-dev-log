# Task Management REST API

A simple REST API built with Python and Flask for managing tasks.

## Features

- Get all tasks
- Get a task by ID
- Create a new task
- Delete a task
- JSON API responses
- Basic error handling

## Tech Stack

- Python
- Flask
- REST API
- JSON

## Run Locally

```bash
pip install flask
python app.py

API:

http://127.0.0.1:5000/api/tasks
