# 🌤️ Weather REST API

A simple Weather REST API built with **Python and Flask** that retrieves real-time weather information for a requested city using an external weather API.

This project is part of my **100 Days of Building in Public** challenge.

---

## 🚀 Features

- 🌤️ Get current weather information
- 🌍 Search weather by city
- 🌡️ Temperature information
- 💧 Humidity information
- 🌬️ Wind speed
- 🤔 Feels-like temperature
- 🌎 Country information
- 📦 JSON API responses
- ✅ Input validation
- ❌ Error handling
- 🔗 External API integration

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Python | Programming language |
| Flask | REST API framework |
| Requests | HTTP/API requests |
| JSON | Data exchange |
| Weather API | External weather data |
